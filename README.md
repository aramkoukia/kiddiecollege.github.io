# Kiddie College static website

A static copy of the Kiddie College website, ready for GitHub Pages.

## Preview locally

You can open `index.html` directly in a browser because its CSS, scripts, and images use local paths.

Alternatively, run a local server:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173/index.html`.

## Publish with GitHub Pages

Push this repository to GitHub, then enable GitHub Pages from the repository settings using the `main` branch and `/ (root)` folder.
